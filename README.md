# PrimeParser
Приложение для оптимизации анализа торговой площадки и поиска самых выгодных сделок на [warframe.market](https://warframe.market/).

## О проекте
PrimeParser - бесплатное приложение для быстрого поиска и отслеживания выгодных предложений на торговой площадке игры `Warframe`. 
Позволяет находить подходящие предложения, сохранять их для отслеживания, обновлять актуальные данные о ценах и быстро подготавливать сообщение для связи с продавцом в игре.
Введя параметры интересующего товара, приложение выводит самое выгодное из актуальных предложений с торговой площадки.

## Установка

1. Загрузите файлы из репозитория в свой проект:
```console
git clone https://github.com/Veidge/PrimeParser
cd PrimeParser
```
2. Установите зависимости:
```console
pip install -r requirements.txt
```
3. Дождитесь загрузки и запустите файл `main.py`.
4. Ознакомьтесь с инструкциями в самом приложении.

## Основной функционал приложения

### Добавление заказа:

> Чтобы добавить какой-либо предмет для отслеживания, необходимо нажать на кнопку `Поиск`. 
В открывшемся окне ввести необходимые данные предмета с [warframe.market](https://warframe.market/). 
Когда все данные будут заполнены, нажмите по кнопке `Подтвердить`.

### Удаление заказа:

> Удалить отслеживание предмета можно при помощи кнопки `Удалить запись`, выбрав нужную запись.

### Связь с покупателем/продавцом:

> Кнопка `Купить` копирует текст сообщения, которое Вы можете вставить в чат игры Warframe для связи с игроком.

### Обновление данных заказа:

> Кнопка, расположенная в левом верхнем углу таблицы с иконкой обновления, позволяет повторно собрать актуальные данные о заказах. 

> Автоматическое обновление данных заказа можно настроить в настройках в пункте `Обновление товаров`.

## Структура

`/data` — директория с JSON-файлами настроек и сохранённых заказов.

`/src` — директория с основными файлами проекта.

> `/src/gui` — директория с файлами интерфейса.
>
> `/src/icons` — директория с используемыми изображениями и логотипами.
> 
> `/src/main.py` — основной файл запуска приложения.

`/tests` — директория с модульными и интеграционными тестами.

`requirements.txt` — файл с необходимыми зависимостями.
